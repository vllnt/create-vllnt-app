# Internationalization (i18n)

## Setup

Uses `i18next` + `react-i18next` for internationalization in React Native.

## Structure

```
i18n/
  index.ts              i18next initialization
  locales/
    en.json             English translations
```

## Adding Translations

1. Add keys to `i18n/locales/en.json`
2. Use in components:

```tsx
import { useTranslation } from 'react-i18next'

export function MyComponent() {
  const { t } = useTranslation()
  return <Text>{t('namespace.key')}</Text>
}
```

## Adding a New Locale

1. Create `i18n/locales/{locale}.json` with same keys as `en.json`
2. Add to resources in `i18n/index.ts`

```typescript
import fr from './locales/fr.json'

const resources = {
  en: { translation: en },
  fr: { translation: fr },
}
```

## Language Detection

Add `expo-localization` for automatic locale detection:

```typescript
import * as Localization from 'expo-localization'

i18n.init({
  lng: Localization.getLocales()[0]?.languageCode ?? 'en',
})
```
