# Internationalization (i18n)

## Setup

Uses `next-intl` for type-safe internationalization with Next.js App Router.

## Structure

```
i18n/
  routing.ts       Locale config (supported locales, default)
  request.ts       Server-side message loading
  navigation.ts    Locale-aware Link, redirect, usePathname
messages/
  en.json          English translations
```

## Adding Translations

1. Add keys to `messages/en.json`
2. Use in components:

```tsx
import { useTranslations } from 'next-intl'

export function MyComponent() {
  const t = useTranslations('Namespace')
  return <h1>{t('title')}</h1>
}
```

## Adding a New Locale

1. Add locale to `i18n/routing.ts` → `locales` array
2. Create `messages/{locale}.json` with same keys as `en.json`
3. Translations are automatically routed via `[locale]` segment

## Server Components

```tsx
import { getTranslations } from 'next-intl/server'

export async function generateMetadata() {
  const t = await getTranslations('Page')
  return { title: t('title') }
}
```

## Navigation

Use locale-aware navigation from `@/i18n/navigation`:

```tsx
import { Link } from '@/i18n/navigation'

<Link href="/dashboard">Dashboard</Link>
```
